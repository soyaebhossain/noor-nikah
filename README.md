# নূর নিকাহ (NoorNikah) — Demo

হালাল ম্যারেজ মিডিয়া প্ল্যাটফর্মের একটি **ফ্রন্টএন্ড ডেমো** (React + Vite)।
সব প্রোফাইল ও তথ্য কাল্পনিক — কোনো ব্যাকএন্ড/ডেটাবেস নেই।

## স্থানীয়ভাবে চালানো (Local)

প্রয়োজন: Node.js 18+ ইনস্টল থাকতে হবে।

```bash
npm install      # প্যাকেজ ইনস্টল
npm run dev      # ডেভেলপমেন্ট সার্ভার (http://localhost:5173)
npm run build    # প্রোডাকশন বিল্ড (dist/ ফোল্ডারে)
npm run preview  # বিল্ড প্রিভিউ
```

## Vercel-এ লাইভ করা

### উপায় ১ — GitHub দিয়ে (সবচেয়ে সহজ)
1. এই ফোল্ডারটা একটা GitHub রিপোজিটরিতে পুশ করুন।
2. https://vercel.com এ লগইন করে **Add New → Project** চাপুন।
3. আপনার রিপো **Import** করুন।
4. Vercel নিজেই Vite ধরে নেবে (Build Command: `npm run build`, Output: `dist`)। কিছু বদলানোর দরকার নেই — **Deploy** চাপুন।
5. কয়েক সেকেন্ডে একটা লাইভ লিংক পাবেন।

### উপায় ২ — Vercel CLI দিয়ে
```bash
npm i -g vercel
vercel        # প্রথমবার লগইন + সেটআপ
vercel --prod # প্রোডাকশনে ডিপ্লয়
```

## ফোল্ডার স্ট্রাকচার

```
├── .gitignore
└── src/

```

## পরবর্তী ধাপ (আসল প্ল্যাটফর্ম)
আসল কার্যকর সাইটের জন্য যুক্ত করতে হবে: ব্যাকএন্ড/API, ডেটাবেস, আসল Auth (মোবাইল OTP),
ছবি আপলোড, পেমেন্ট গেটওয়ে (bKash/Nagad/SSLCOMMERZ), এবং NID ভেরিফিকেশন।
সংবেদনশীল ব্যক্তিগত তথ্য থাকায় ডেটা সুরক্ষা ও প্রাইভেসি নীতি সবচেয়ে গুরুত্বপূর্ণ।
